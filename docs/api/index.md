# API

<p class="vo-intro">An open-source Python package to explore, visualise and analyse mosquito genomic data interactively.</p>

<div class="vo-two-col">
<div>

```text
pip install <package-name>
import <package_name>
data = <package_name>.Anopheles()
```

<p class="vo-note">Package name to be agreed (renaming of the current API)</p>

## What you can do

<div class="vo-grid vo-grid-2">
  <div class="vo-card">Access data from the cloud</div>
  <div class="vo-card">Explore samples by country, date and species</div>
  <div class="vo-card">Compare allele frequencies by region and time</div>
  <div class="vo-card">Population structure (PCA)</div>
  <div class="vo-card">Genome-wide selection scans</div>
  <div class="vo-card">Haplotype clustering and networks</div>
</div>
